# 順序回路 学習ラボ（sequential-lab）

論理回路の授業（第16〜22回）の練習問題を、シミュレーションしながら解くための学習ツール。

## 起動方法

```
npm install
npm run dev
```

表示された URL（通常 http://localhost:5173）をブラウザで開く。

## テスト

```
npm test          # Vitest
npm run typecheck # 型チェック
```

## 資料

- `docs/lectures/` 授業スライド（16.pdf〜22.pdf）。リポジトリには入れていないので、手元で置く
- `docs/problems.md` スライドから書き起こした回路・初期値・答え、スライドとの食い違いの一覧

## 構成

- `src/engine/` シミュレーションエンジン（UI に依存しない TypeScript）
  - `types.ts` 回路・刺激列・結果の型
  - `simulate.ts` 本体。`simulate(回路, 刺激列, オプション)` が全信号の変化の一覧を返す
  - `build.ts` 回路を書くための補助（`ff`、`gate`、`wire` など）
  - `stimulus.ts` クロックと入力の刺激列を作る補助
  - `sample.ts` 結果から値・動作表・バスの履歴を読む補助
- `src/problems/circuits.ts` 授業の回路
- `tests/fixtures/scenarios.ts` スライドの答えを手で書き起こした期待値

## エンジンの考え方

- 時間の単位は ns。授業の回路はクロック周期 100ns で動かしている。
- **理想モード**（`mode: 'ideal'`）は遅延 0。同じ時刻の中で、原因 → 結果の順に番号（delta）を付けて処理する。同じエッジで動く FF は、エッジ直前の入力を読む。
- **遅延モード**（`mode: 'delay'`）は、FF（既定 8ns）、ゲート（既定 5ns）、配線（`wire` で名前を付けた配線ごと）に遅延を持つ。
- 配線遅延は「遅延より短いパルスは消える」（慣性、標準）と「そのまま遅れて届く」（`wireModel: 'transport'`）を選べる。
- CLR が働いている間は、クロックエッジを無視する。CLR と PR が同時に働いたら CLR を優先する。
- 変化ごとに理由（クロックエッジ・エッジ直前の入力・動作、CLR／PR、ゲートの入力）を記録する。
